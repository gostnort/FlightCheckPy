# Flight Check --- Python 版本

## 项目简介

主要用于解析和验证 **HBPR** 数据，提供数据库构建、记录处理、航空公司命令分析（含时间线版本）、以及基于 TKNE ↔ CKIN CCRD 的 Excel（EMD）生成。

## 快速开始

### 环境准备

1. **下载项目**
   ```bash
   git clone https://github.com/gostnort/FlightCheckPy
   cd FlightCheckPy
   ```

2. **创建虚拟环境**
   ```bash
   python -m venv .venv
   .venv/scripts/activate  # Windows
   ```

3. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```

### 运行应用

#### Web 界面
```bash
streamlit run ui/main.py
```
纯命令行会带有console messages。
  - 可以运行``start_ui.bat`` 这个是带有内网服务的启动命令。
  - 可以运行``start_ui.py`` 这个是没有console，提供了内网服务和任务托盘图标的启动程序。
  - 设置了更容易客户编辑的快捷方式
  
**注意**: 首次运行时会显示登录界面，需要管理员提供的有效凭据。

## 版本更新

### v0.63 新特性
- ⚡ **核心架构升级**: 全面迁移至 **内存数据库**，显著提升了所有数据操作的性能和流畅度。
- 💾 **自动持久化**: 引入了智能 **自动保存** 机制。在修改记录或切换数据库时，内存中的数据会自动同步回磁盘文件，确保数据安全不丢失。
- 🔐 **IP会话管理**: 实现基于IP的会话跟踪系统，支持：
  - 浏览器关闭后60秒内自动登录
  - 干净的登出（不关闭服务器）
  - 支持本地和局域网访问（127.0.0.1 和 192.168.x.x）
  - 每个用户服务器同时只允许一个IP登录
  - 无需手动清理进程
- 🔧 **代码重构**: 对整个项目的代码进行了深度重构，统一了数据库访问接口，提高了代码的可维护性和稳定性。
- 🐛 **问题修复**: 修复了多个在重构过程中引入的 Bug，并修正了原始文本（Orig Txt）导出功能，确保其能正确处理换行和保留原始格式。
- 🧭 **多源数据库发现与位置指示**:
  - 支持从自定义文件夹、默认 `databases/` 目录和根目录发现数据库
  - 使用 📁/🏠/📄 图标清晰标识数据库来源
  - 支持 **Windows 原生文件夹选择器** 并持久化自定义目录
- 🧠 **统计缓存管理**:
  - 引入智能缓存机制，仅在数据变更时自动失效和刷新
  - 主页与数据库页统一显示核心指标：**Max HBNB**、**缺失数量**、**Accepted** (成人+婴儿，含 J/Y 拆分)
- 📋 **强大的命令处理**:
  - 支持导入、编辑和查看多种航空公司命令
  - 新增 📅 **时间线** 视图，提供命令的版本化管理、内容对比和一键恢复
  - 提供数据库迁移和命令清理等维护工具
- 🔐 **登录与会话管理**:
  - 使用 Session State 持久化用户会话，避免重复登录
  - 登出时自动清理会话和临时文件
- 🎨 **模块化UI架构**:
  - `ui/` 目录重构为功能模块（`database/`, `process_records/`），结构更清晰
  - 引入可复用组件 (`ui/components/`)，如 `main_stats.py` 和 `database_selector.py`，统一界面风格
  - 页面导航高亮，优化内容区域显示，提升用户体验
- 🧹 **文件与页面**:
  - 支持自定义数据库目录，方便管理
  - 页面导航高亮，内容区域显示优化

## 使用说明

1. **安全登录**: 使用管理员提供的凭据登录系统
2. **准备数据**: 确保 HBPR 数据文件格式正确
3. **选择界面**: 根据需要选择桌面应用或 Web 界面
4. **处理数据**: 使用相应的处理功能解析和验证数据
5. **查看结果**: 检查处理结果和错误报告
6. **导出数据**: 将处理结果导出为所需格式
7. **安全登出**: 使用完毕后及时登出系统

## 支持格式

- **输入**: HBPR 文本记录
- **输出**: CSV, 数据库记录
- **数据库**: SQLite

## 系统要求

- Windows Python 3.12
- 推荐使用虚拟环境
