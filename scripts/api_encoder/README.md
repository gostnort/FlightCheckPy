# Gemma3 聊天命令行界面

一个功能强大的交互式聊天界面，支持与 Google Gemma 模型实时对话，具有动态模型选择、文件读取、多行输入等高级功能。

## 核心功能

### 🤖 动态模型支持
- **实时获取模型列表** - 从 Google Generative AI API 动态获取最新支持的 Gemma 模型
- **自动 Token 限制** - 每个模型的 Token 限制直接从 API 获取，无需硬编码
- **自动适应新模型** - 当 Google 发布新模型时，程序自动支持，无需修改代码

### 💬 对话功能
- **完整对话历史** - 保存对话记录，支持上下文理解
- **实时 Token 计算** - 显示当前对话的 Token 使用情况
- **多行输入支持** - 支持输入长篇代码、文章等内容
- **中英文混用** - 支持中文和英文对话

### 📄 文件读取功能
用反引号引用 txt 文件，文件内容自动被读取并发送给 Gemma 分析：

```
方式1: `filename.txt`
  - 在脚本所在目录中查找文件
  - 示例: 请帮我总结 `report.txt` 中的内容

方式2: `C:\path\to\file.txt` 或 `/path/to/file.txt`
  - 使用完整路径查找文件
  - 示例: 分析 `C:\data\analysis.txt`
```

### 🔐 安全认证
- **预编码 API 密钥系统** - 真实 API 密钥被预编码成伪码
- **用户名验证** - 只有正确的用户名才能解码 API 密钥
- **安全上传** - 代码可以安全地上传到 GitHub，不会泄露密钥

## 聊天界面使用方法

### 启动程序

```bash
cd scripts/api_encoder
python gemma_chat_cli.py
```

### 交互流程

1. **输入用户名** - 通过用户名解码 API 密钥
2. **自动获取模型** - 从 API 获取最新的 Gemma 模型列表
3. **选择模型** - 选择要使用的模型
4. **开始对话** - 与 Gemma 进行实时对话

### 特殊命令

| 命令 | 功能 |
|------|------|
| `/help` | 显示完整帮助信息 |
| `/multi` | 启动多行输入模式 |
| `/clear` | 清空对话历史 |
| `/tokens` | 显示当前 Token 使用情况 |
| `/history` | 显示对话历史摘要（最近5条） |
| `/model` | 显示当前模型信息 |
| `/exit` | 退出聊天界面 |

### 高级用法

**多行输入** - 在行末输入 `\` 或使用 `/multi` 命令进入多行输入模式，支持输入长篇代码、文章等

**文件分析** - 使用反引号引用文件：`请帮我总结 `data.txt` 的内容`

**组合使用** - 结合多行输入和文件引用处理复杂任务

# 心情描述生成器

根据航班旅客数量和收入生成描述心情的中文字词。

## 功能说明

- 输入现金和总金额，根据比例确定心情类别
- 心情分级：5%=轻松，10%=有点累，30%=惨兮兮，50%+=惨绝人寰
- 使用Gemma 1B模型生成对应的中文心情描述
- 使用预编码系统保护API密钥安全
- 自动清理特殊符号，只保留中文字符
- 1秒超时保护，超时返回"心情失败"

## 使用方法

### 运行程序
```bash
cd scripts/api_encoder
python gemma3_client.py
```

### 输入信息
1. 输入用户名
2. 输入现金金额(元)
3. 输入总金额(元)

### 输出结果
程序将根据现金比例生成对应心情描述：
- 5%以下：轻松愉悦的心情
- 10%以下：有点累但还行
- 30%以下：惨兮兮的心情
- 50%以上：惨绝人寰的心情
- 心情失败（超时时返回）

## 安全特性

- 真实API密钥被预编码成伪码列表
- 用户名不出现在代码中，防止泄露
- 使用API密钥后缀验证解码结果正确性
- 只有知道正确用户名的用户才能解码
- 未授权用户无法还原真实API密钥
- 可以安全地上传到GitHub

## 文件说明

| 文件 | 说明 |
|------|------|
| **`gemma_chat_cli.py`** | Gemma3 聊天命令行界面 - 支持动态模型选择、文件读取、多行输入 |
| **`api_encoder.py`** | API 密钥预编码器和管理工具 |
| **`gemma3_client.py`** | 心情描述生成器主程序 |

## 系统要求

- Python 3.6+
- `google-generativeai` 库
- 有效的 Google Generative AI API 密钥
- 网络连接

## 注意事项

- 确保网络连接正常
- 用户名必须正确才能使用
- 模型列表会根据 Google API 的可用性动态变化
- Token 限制由 API 实时提供，无需手动更新
- 对话历史会占用 Token，可使用 `/clear` 清理
